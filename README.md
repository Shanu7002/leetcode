# 🎯 LeetCode: Algorithm & Data Structure Optimization

This repository document my progress through various algorithmic challenges, primarily from LeetCode and Advent of Code. My goal is to master **Problem Solving Patterns** and achieve **Optimal Runtime/Memory** performance.

## 🚀 The Approach
Instead of just chasing the "Accepted" status, I focus on the evolution of the solution:
1. **Identify the Pattern:** (e.g., Two Pointers, Sliding Window, Greedy).
2. **Brute Force:** Establish a baseline $O(n^2)$ or $O(2^n)$ solution.
3. **Optimize:** Refactor to $O(n \log n)$ or $O(n)$ using efficient data structures.
4. **Benchmark:** Aim for the "Beats 95%+" bracket in LeetCode.

## 📂 Repository Structure
Solutions are organized by pattern rather than difficulty to emphasize architectural understanding:

* **/Arrays_and_Hashing** - Frequency maps, prefix sums, and set-based lookups.
* **/Two_Pointers** - Linear traversals from both ends or slow/fast pointer logic.
* **/Sliding_Window** - Dynamic and fixed-size window optimizations.
* **/Binary_Search** - Logarithmic search patterns and boundary condition handling.
* **/Low_Level_C** - Deep dives into memory, pointers, and manual optimizations.

## 🛠️ Tech Stack
* **TypeScript:** Rapid prototyping and logic validation.
* **C:** Understanding "under the hood" memory management and pointer arithmetic.
* **Go / Java:** (Upcoming) Scaling solutions with production-grade languages.

## 📈 Performance Tracking
Each solution file contains a header with:
- **Difficulty:** (Easy/Medium/Hard)
- **Time Complexity:** Analytical growth (Big O).
- **Space Complexity:** Memory footprint analysis.
- **Notes:** Brief explanation of the "Aha!" moment or the specific optimization used.
